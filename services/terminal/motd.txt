
  Alpine Linux 3.24 web terminal on Railway
  --------------------------------------------------------------------------
  Saved:     /home/alpine is a Railway volume. The rest of the system resets
             on every redeploy.
  Sessions:  tmux keeps this shell running when the tab closes. Reopen the URL
             to resume. New window: Ctrl-b c. Next: Ctrl-b n. Detach: Ctrl-b d.
             Separate session: add ?arg=work to the URL.
  Packages:  sudo apk add PACKAGE works now but resets on redeploy. To keep
             packages, list them in the service variable ALPINE_EXTRA_PACKAGES:
             Railway bakes them into the image. Compilers: add build-base.
  Tools:     bash, git, curl, vim, nano, htop, python3, pip, pipx, node, npm
             (npm -g installs into ~/.npm-global). Alpine uses musl libc.
  Copying:   hold Shift while selecting text (tmux mouse mode is on).
  Fair use:  Railway's Acceptable Use Policy applies. No crypto mining,
             proxies, anonymizers or torrenting.
  Banner:    touch ~/.hushlogin hides this message.
